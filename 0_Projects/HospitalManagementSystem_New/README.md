# Hospital Management System

A console-based Python OOP project with CRUD operations for doctors, employees, and patients.

## Run

Open a terminal in this folder and run:

```bash
python main.py
```

## Files

- `main.py` — application menu and object setup
- `hospital.py` — hospital details and CRUD operations
- `doctor.py` — Doctor class
- `employee.py` — Employee class
- `patient.py` — Patient class
- `utils.py` — reusable input and validation helpers

Data is currently stored in memory and will reset when the program closes. JSON persistence is a later step.
